# Support

Thank you for using QueryCost Sentinel.

- **Questions and general discussion**: Open a [GitHub Discussion](https://github.com/tomorrm/querycost-sentinel/discussions) or [Issue](https://github.com/tomorrm/querycost-sentinel/issues).
- **Bug reports**: Use the [bug report template](https://github.com/tomorrm/querycost-sentinel/issues/new?template=bug_report.yml).
- **Feature requests**: Use the [feature request template](https://github.com/tomorrm/querycost-sentinel/issues/new?template=feature_request.yml).
- **Security vulnerabilities**: Please see [SECURITY.md](./SECURITY.md) and report privately.

Commercial support is not provided by the maintainers.
